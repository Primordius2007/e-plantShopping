# e-plantShopping

e-plantShopping is a React-based web application developed as part of the IBM Coursera Front-End Development program.

## Project Overview

The e-plantShopping application is an online plant shopping platform where users can browse plants, add items to a cart, and manage their selections before checkout. The project demonstrates core React concepts such as components, routing, state management, and UI interaction.

## Features

- Landing page with navigation
- Plant listing page
- Shopping cart functionality
- Responsive user interface

## Technologies Used

- React
- JavaScript
- HTML
- CSS
